# Crayon video stats & learnings

Written by the daily 21:45 report run. One line per video per day + short learnings. The video runs read this before writing scenes.

## Learnings
- 2026-10-13: #1 TikTok got 270 views (98% For You) but average watch was 7 s of 23 s, almost nobody watched to the end → hook too slow. New hook rule added to AUTOMATION.md.

- 2026-10-14 (YouTube Studio, #1 230 million years, 1 day): 737 views, only **20.5 % stayed to watch** (4 of 5 swipe in the first 1–2 s), but those who stayed watched **19 s of 23 s (84 %)** and 5 shared it. → The story/pacing works; ONLY the first 1–2 seconds lose people. Fix the opening, keep the rest. Also 0 comments → always give viewers an explicit question.
- 2026-10-14: #2 Save the tomato on TikTok got the same test reach as #1 (275 vs 270, ~99 % For You) but held viewers worse: avg 4 s of 27 s (#1: 7 s of 23 s), 1 like vs 8. TikTok gives each new video ~270 test views either way → the first 3 s decide everything; the dino "what's for dinner?" opening beat the tomato/food-waste opening.
- 2026-10-15: #5 Fridge interview (TikTok) got the most likes so far (12 on 268 views, ~4.5 %) but avg watch only 5 s / 23 s; #1 dino still holds longest (7 s). App-screen demos (App #1, App #2) both hold just ~1 s on TikTok → open with a crayon story/character, not the app UI.
